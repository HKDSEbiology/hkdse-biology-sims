How to use this simulation
  1. Step 1 — Select gametes: Click one allele in each pair for the sperm / egg (green), or use Random select to coin-flip all pairs at once.
  2. Step 2 — Fertilise: When both parents show every pair selected, press FERTILISE to see the child’s phenotype.

Basic mode uses monogenic traits only (8 pairs). Dominance is already built into each allele (capital = dominant), so you only choose which allele is inherited. Switch to Advanced for the full 23-pair model. Use each parent’s Reset button to clear that side and try again.

  1. Step 1 — Dominance (unlocked): In each pair, click which homolog shows the dominant allele (gold). The other is dimmed.
  2. Step 2 — Lock father and mother when you are happy with allele labels.
  3. Step 3 — Select gametes (locked): Click one chromosome in each pair for the sperm / egg (green), or use Random select if you prefer not to choose one by one.
  4. Step 4 — Fertilise: When both sides show all pairs selected and locked, press FERTILISE to build the child’s face from the combined genotype.

Tip: after Lock, use Random select to coin-flip that parent’s gamete chromosomes at once. Use Basic for a shorter monogenic lesson (8 pairs).

Basic mode — monogenic traits (8 pairs)

Numbered chromosome pairs stand in for face traits. Each trait below follows monogenic inheritance (one gene, two alleles, complete dominance). Pair 23 is sex determination (XX / XY), not a dominant/recessive gene. Skin, hair, and eye colour are left out here and introduced later in Advanced mode.

Active pairs: #1, 8, 9, 13, 14, 18, 20, and 23. A dominant phenotype appears if at least one dominant allele is present.

Activity 1 — Make a Face
From genotype to phenotype

Hands-on chromosome cards and / or this simulation · Basic monogenic model (8 pairs)

Level: Secondary Biology / Combined Science (Biology)
Time: ~35–50 minutes
Group size: 2–4 students
Pairs used: #1, 8, 9, 13, 14, 18, 20, 23

By Ms Lai Kam Fung · Classroom teaching use

Learning objectives

  • Explain that each parent contributes one chromosome from each homologous pair to the offspring.
  • Record a zygote genotype and deduce the matching phenotype using complete dominance.
  • State how sex is determined by XX / XY (egg always contributes X; sperm brings X or Y).
  • Appreciate why siblings can look different even with the same parents (random assortment of alleles).

Materials

  • Option A (hands-on): print the chromosome cut-out sheet (below) in colour — pink = mother, blue = father. Cut along the dashed lines.
  • Option B (digital): use Basic mode in this same page.
  • Face portrait: coloured pencils to draw the child’s face or an AI image tool to generate a face at about age 15 (must match every phenotype in Table 2).

Procedure

  1. Line up the mother and father chromosomes by pair number (or open Basic mode above).
  2. For each pair, randomly pick one chromosome from the father and one from the mother. Record both alleles in Table 2.
  3. Write the zygote genotype (capital allele first when heterozygous, e.g. Rr). Circle or write the phenotype using Table 1.
  4. Name your baby and state the sex from pair 23.
  5. Create the child’s face (choose one): draw it by hand or use AI to generate an image — so that every trait in Table 2 is clearly shown. Paste or attach the AI image in the space below if you use AI.

Reminder: one dominant allele is enough for the dominant look; recessive needs two recessive alleles (e.g. rr). For a shorter Basic lesson, focus on pairs #1, 8, 9, 13, 14, 18, 20, 23.

Reflection
